# IP Detector

Определяет текущий IP-адрес, получает геогр инфо через сервис IPinfo и загружает полученные данные на Яндекс.Диск в формате JSON

## Настройка токена

Токен Яндекс.Диска -программа считывает его из переменной окружения `YANDEX_TOKEN`.

Перед запуском программы в терминале необходимо выполнить:

```
$env:YANDEX_TOKEN="ваш_токен"
python main.py
```

## Результат работы

Программа создаёт на Яндекс.Диске папку `ip_detector` и загружает в неё файл `ip_info.json`
